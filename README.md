# Galgame ボイスカット無効化ガイド

ゲーム側にボイスカット設定が存在しない作品について、現在再生中のボイスを次のボイスが始まるまで継続させる方法をまとめるプロジェクトです。

## 対応ゲーム

| ゲームタイトル | エンジン | 対応方法 |
| --- | --- | --- |
| [あまえて☆にぃに2〜バブみのある妹たちは、にぃにの××をえらいえらいしてあげたいんです♪](games/amaete-niini-2/) | TyranoScript | PowerShellパッチ |

表記ゆれを含む検索用の一覧は [`games/catalog.yml`](games/catalog.yml) にあります。

## このリポジトリでいう「ボイスカット」

次のテキストへ進んだ時点で、再生中のボイスを停止する動作を指します。本プロジェクトでは、ボイスのないテキストへ進んでも現在のボイスを継続し、次のボイスが再生された時点で切り替わる状態を目標とします。

## 注意事項

- 必ずゲームを終了してから作業してください。
- 対応バージョンとファイルのSHA-256が一致することを確認してください。
- セーブデータとは別に、変更対象ファイルのバックアップも保管してください。
- ゲーム本体、シナリオ、画像、音声などの著作物は配布しません。
- 使用は自己責任です。販売元や開発元への問い合わせは行わないでください。
