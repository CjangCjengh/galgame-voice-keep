対象について

古いギャルゲーには、ボイスキープの設定が見当たらなかったり、ボイスカットをオフにしても一部の台詞でボイスが止まったりする作品があります。

ここでは、ゲームごとに確認できた対処法を短くまとめ、必要な場合だけパッチを公開しています。ゲーム本体のデータは含めません。

確認項目設定画面に項目がなくても、ウィンドウ上部のメニューバーに設定がある場合があります。
