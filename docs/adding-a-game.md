# 対応ゲームの追加方法

## 1. 追加対象

ゲーム内にボイスカット動作を切り替える設定がなく、設定ファイルの変更またはパッチが必要な作品を対象とします。ゲーム内の設定だけで変更できる作品は原則として追加しません。

## 2. ディレクトリ名

`games/` 以下には、英小文字・数字・ハイフンだけを使った短いslugを作成します。正式な日文タイトルはファイル名ではなく、`README.md`、`game.yml`、`games/catalog.yml` に記載します。

```text
games/example-game/
├─ README.md
├─ game.yml
└─ patch/
```

## 3. 検索用情報

次の情報を `game.yml` と `games/catalog.yml` に記録します。

- 正式な日文タイトル
- よく使われる略称
- 記号を省略した表記
- 全角・半角などの代表的な表記ゆれ
- パッケージ版、DL版などの対象版
- 使用エンジン

無関係なキーワードを検索目的で追加しないでください。

## 4. READMEの構成

各ゲームの説明は簡潔にまとめ、原則として次の順序にします。

1. 対象バージョン
2. 症状
3. ボイスカットを無効にする方法
4. パッチの使い方
5. 元に戻す方法
6. 動作上の変化
7. このゲームから得られた知見

## 5. パッチの要件

- 対象ファイルのサイズとSHA-256を検証すること。
- 未対応版や変更済みファイルへの書き込みを拒否すること。
- 書き込み前にバックアップを作成すること。
- 適用済みかどうかを判定できること。
- 復元機能または明確な復元手順を用意すること。
- ゲームのインストール先を固定しないこと。
- ゲーム本体のデータを同梱しないこと。

## 6. 公開前の確認

パッチ適用、二重適用、状態確認、復元をそれぞれテストします。また、ゲーム本体のファイルや個人のインストールパスがコミットに含まれていないことを確認します。
