# 対応ゲームの追加方法

## 1. 追加対象

ゲーム内にボイスカット動作を切り替える設定がなく、設定ファイルの変更やパッチが必要な作品を扱います。ゲーム内の設定だけで変更できる作品は追加しません。

## 2. ディレクトリ名

`games/` 以下には、英小文字・数字・ハイフンだけを使った短いslugを付けます。正式な日本語タイトルはファイル名ではなく、`README.md`、`game.yml`、`games/catalog.yml` に書きます。

```text
games/example-game/
├─ README.md
├─ game.yml
└─ patch/
```

## 3. 検索用情報

次の情報を `game.yml` と `games/catalog.yml` に登録します。

- 正式な日本語タイトル
- よく使われる略称
- 記号を省略した表記
- 全角・半角などの代表的な表記ゆれ
- パッケージ版、DL版などの対象版
- 使用エンジン

検索用だけの無関係なキーワードは追加しないでください。

## 4. READMEの構成

各ゲームの説明は簡潔にまとめ、基本的に次の順序にします。

1. 対象バージョン
2. ボイスカットを無効にする方法
3. パッチの使い方
4. 元に戻す方法
5. 動作上の変化
6. 補足

## 5. パッチの要件

- 対象ファイルのサイズとSHA-256を検証してください。
- 未対応版や変更済みファイルには書き込まないでください。
- 書き込み前にバックアップを作成してください。
- 適用済みかどうかを判定できるようにしてください。
- 復元機能か、わかりやすい復元手順を用意してください。
- ゲームのインストール先を固定しないでください。
- ゲーム本体のデータを含めないでください。

## 6. 公開前の確認

パッチ適用、二重適用、状態確認、復元をそれぞれテストします。また、ゲーム本体のファイルや個人のインストールパスがコミットに含まれていないことを確認します。
